🛠️ Installation du launcher Préconfigurée

Télécharger l'instance PrismMC

  2. Extraire le contenu du zip
  3. Lancer minecraft.cmd (ou launcher/prismlauncher.exe)

Prism est un launcher alternative pour minecraft qui permet d'avoir plusieurs versions installées simultanément, et permet de gérer facilement différents modpacks ⚡
